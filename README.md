# KRONOS 360 - Capa de Confianza Anti-Falsificación

**El sistema que el mercado negro no puede clonar.**

Plataforma B2B para generación de folios infalsificables con sello de tiempo criptográfico (TimeLock ISO 8601), hash SHA-256 y registro en blockchain Polygon.

## 🚀 Demo en Vivo
- **Ver Original:** `/verify/FDV-DEMO-00001`
- **Ver Clon:** `/verify/CLON-DEMO-99999`

## 🛠️ Tecnología
- **Next.js 14** (App Router) + TypeScript + Tailwind CSS
- **Supabase** (Base de datos con restricciones UNIQUE anti-clon)
- **Polygon** (Anclaje de hash en blockchain público)
- **Kernel Offline** (72 hashes en cascada + firma Ed25519)
- **Protocolo KÓDICE** (MIS, MAS, MRA, MTI, MAR)

## 🔐 Seguridad
- Middleware de protección de rutas (`middleware.ts`)
- Rate Limiting anti-scraping (`lib/rateLimit.ts`)
- Guardian Assistant que documenta cada evento (`lib/guardian.ts`)
- Cumplimiento **NOM-151** e **ISO 27037** (`lib/evidence.ts`)
